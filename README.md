# JKBeat

A complete single-page marketing showcase using Next.js App Router, React, TypeScript, Tailwind CSS v4, a shadcn-style Radix/CVA Button component, Material Symbols, and Framer Motion.

## Run locally

Install Node.js 20.9+ (Node 22 recommended), then open a terminal in this directory:

```powershell
npm install
npm run dev
```

Open http://localhost:3000. For a production build:

```powershell
npm run typecheck
npm run build
npm start
```

Dependencies are installed, TypeScript validation passes, and the production build completes in the authoring session. The local site was tested in a browser, including loading the featured YouTube player after the visitor presses Play. Lighthouse auditing has not been run, so no performance or accessibility score is claimed. Commit the generated `package-lock.json` before publishing.

## Customize

- **Colors:** edit the `:root` and `[data-theme=light]` tokens in `app/globals.css`. Purple and cyan accents, surfaces, text, borders, and button colors are shared across the page.
- **Links and downloads:** edit `lib/config.ts`. Set `github` to the official repository URL, and each `downloads` value to an official release or file URL. Set Discord, Twitter/X, and contact URLs there too. Empty URLs show clear coming-soon feedback, rather than sending users to an unrelated account. GitHub Issues is derived from the configured repository.
- **Demo downloads:** unconfigured buttons announce `Download started · Demo only; no file is downloaded.` Configured links open in a new tab; the browser/server handles the actual transfer. The page does not claim a file completed downloading.
- **Copy and tracks:** edit `app/page.tsx`. All demo songs and artist names are invented. Album artwork is original CSS geometry, so no remote album-image service is needed.
- **SEO:** edit `app/layout.tsx` and the generated social card in `app/opengraph-image.tsx`. After choosing a production domain, add `metadataBase: new URL('https://your-domain.example')` to the metadata object and a canonical URL. The PNG social card is generated by Next.js.
- **Legal pages:** footer links currently show coming-soon notices. Replace these with approved License, Privacy, and Terms pages before a public launch; no legal text or software license is invented here.
- **Typography:** Inter and Material Symbols Outlined/Rounded load from Google Fonts. Self-host these fonts if offline font support or avoiding third-party font requests is required.

## Components and interactions

Named reusable components live in `app/home.tsx`: Navbar, Hero, AppMockup, FeatureCard, TeamCard, InterfaceCarousel, DownloadCard, StatsStrip, and Footer. The route entry point is `app/page.tsx`; this separation keeps the components reusable while satisfying Next.js page-module rules. The shared Button lives in `components/ui/button.tsx`, with shadcn configuration in `components.json`.

The preview includes searchable tracks, library/liked views, a functional favorite toggle, track selection, previous/next controls, simulated play/pause and progress, a volume slider, mood selection, genre chips, and import feedback. The hero player presents Jennifer Lopez and Pitbull’s “On The Floor” with the official YouTube video. It loads only after the visitor presses Play, using YouTube’s privacy-enhanced `youtube-nocookie.com` embed; playback availability is controlled by YouTube. Downloaded/Cached/Local/Top 50 show the sample library for layout demonstration. The four interface tabs display a player, library, discovery screen, and adjustable 10-band equalizer with reset.

Theme preference persists locally. On-scroll counters and Framer Motion reveals respect reduced motion. Navigation includes a mobile menu and skip link. Tabs use ARIA roles and arrow/Home/End navigation, form controls have labels, and toast announcements use a polite live region.
